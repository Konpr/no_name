- **Есть:** ввод 2–4 фаз `0.00 | -2 | 31`, `0.70 | -8 | 24`; строгая проверка, отдельный opt-in; raw HF hidden_states CLIP-L; реально выполняемые блоки OpenCLIP-G; подготовка conditioning заранее; trace и PNG Info; read-only предпросмотр.

# Absolute Layer Timeline — техническая спецификация (план, НЕ реализовано в 0.3.3)

## Мотивация

Пользователь хочет задавать пример: «шаги 1–14: CLIP-L `hidden_states[-2]`, CLIP-G `block 31`; шаги 15–20: CLIP-L `hidden_states[-8]`, CLIP-G `block 24`». Текущая версия умеет относительные фазовые значения, но не умеет **вводить абсолютные индексы** и **привязывать их гарантированно к номеру шага самплера**.

## Пользовательский интерфейс

Оставить панели Gradio в txt2img/img2img; не заменять UI целиком на HTML. Небольшой `Layer Map` вычисляет из фактических данных checkpoint опорный слой L, модельный G, разрешённые номера и веса. В Phase Card выбран режим `Relative | Absolute` и по два поля `CLIP-L hidden_states[-N]` и `OpenCLIP-G block K`, начало `0.25 / шаг 15`, опционально interpolation mode. Каждый Phase Card — отдельная строка в общей компактной шкале. Сначала 2–4 фазы.

## Семантика

- Native A1111 `CLIP_stop_at_last_layers` — глобальная целочисленная настройка. `sdxl_clip_l_skip` решает, применяется ли она к SDXL CLIP-L. Отдельной глобальной `CLIP_G_stop_at_last_layers` нет.
- Абсолютный слой не зависит от выбранного относительного reference. У CLIP-L видимые HF `hidden_states` — от embedding `[0]` до финального выходного состояния, которое может отличаться по LayerNorm от `last_hidden_state`. CLIP-G — физические номера блоков (1–32), pooled отдельно.
- Точки переключения при `step=15` относятся к определению пользовательского sampler step, а не произвольно усечённому `total_steps`. При недоступных progress signals — предупреждение, fallback только по явному согласию.
- Перед генерацией подготовить все positive/negative conditioning (с учётом prompt scheduling/SDXL микро-кондиционирования), проверить формы и структуру, применить по времени. С REGION — отдельно подготовить версионно согласованные региональные ветви, иначе безопасно не переключать.

## Проверки

1. L[-2] + G31 native baseline и точные метаданные.
2. Phase 1 L[-2] → Phase 2 L[-8] начиная с шага 15 (Euler 20 steps) и проверка Phase Trace.
3. G31 → G24 независимо от L, pooled=native.
4. Математическое совпадение Relative и Absolute mode для эквивалентных индексов, проверка LayerNorm.
5. Невалидный слой, TI/LoRA/ControlNet, Hires, REGION, batch, Interrupt не оставляют мусорные хуки.

## Статус

Не включено в ZIP 0.3.3; сначала исправить и подтвердить native/fractional reference и старый 4-phase progress по результатам GPU.
