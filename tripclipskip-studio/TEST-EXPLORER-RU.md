# Проверка Layer Explorer 0.2.0-preview на вашей сборке A1111

## Быстрый тест

1. Сделайте резервную копию пресетов: `extensions/tripclipskip-studio/presets/user_presets.json` (если файл существует). Отключите старую версию TripClipSkip, замените **только каталог расширения**, не заменяйте `modules` пользователя. Перезапустите A1111.
2. Выберите тот же SDXL checkpoint, что использовали для теста Dual-Phase. В `txt2img` поставьте **seed=123456789**, Euler, 20 шагов, CFG=7, 768×768, Batch size=1, Batch count=1. На время теста отключите Hires Fix, Refiner, ControlNet и случайные макросы.
3. В панели **TripClipSkip Studio** выберите `CLIP reference=a1111`, `Interpolation=lerp`. Значения L/G панели не важны: скрипт Explorer задаёт их на каждой ячейке; он принудительно отключает Dual-Phase только для серии.
4. Внизу `txt2img → Scripts` выберите **TCS Layer Explorer (fixed seed)**. Введите `CLIP-L = 1,1.5,2`, `OpenCLIP-G = 1,1.5`. Нажмите Generate.
5. В результате должно быть **7 элементов в галерее:** 1 подписанная сетка + 6 отдельных изображений. Сверьте PNG Info каждой картинки: `TCS CLIP-L` и `TCS CLIP-G` должны соответствовать подписям. Изображения должны различаться, но их seed должен совпадать.
6. После Explorer переключите Scripts обратно на `None` и проверьте обычную генерацию с Dual-Phase: она по-прежнему должна менять изображение. Затем используйте `REGION{...}` с обычным дробным CLIP; поведение REGION не должно ухудшиться.

## Проверка Hires Fix отдельно

В обычном режиме без Explorer включите Dual-Phase 1→3 при 0.5. Запустите генерацию с Hires Fix, затем посмотрите терминальный лог:

`[TripClipSkip Studio] Dual-Phase counters: base denoiser calls=N, phase2 calls=M, Hires calls=K`

Сравните с генерацией без Hires. `K` может быть 0, если хуки Hires не распознаны: тогда пришлите полный лог с версией A1111 и названием сэмплера. Пока не утверждаем, что функция полностью проверена.

## Если что-то не работает

Пришлите: 1) полный traceback из терминала; 2) PNG Info или скрин результата; 3) название модели, sampler и включён ли REGION/Hires. В этой среде тесты были только CPU/mock, поэтому GPU-совместимость не подтверждена.

## Ограничения

- Explorer 0.2.0 — только txt2img; Hires рекомендуется сначала выключить.
- Для 16 ячеек при 1024×1024 может потребоваться больше времени и RAM, чем для одного кадра.
- Не поддерживается Refiner/Hires checkpoint swap, не выполняется Dual-Phase внутри сравнения.
- REGION + Dual-Phase по-прежнему защищён ограничением версии 0.1.2.
